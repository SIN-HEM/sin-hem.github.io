This website

The current bitsMAYA pages are static HTML and CSS. They do not include contact forms, account registration, embedded analytics, advertising scripts, or app functionality. They do not themselves set cookies or use browser storage.

The site is hosted on GitHub Pages. GitHub may process technical information associated with visits under its own policies. See the GitHub General Privacy Statement for hosting-related information.

Links to GitHub or other external services take you to services governed by their own privacy policies.

Games and applications

KhoKho and API Workbench are current development projects. Anter is upcoming. Their data practices have not yet been documented on this website.

Before publication, each app will need privacy information that reflects its actual behavior, including any account data, analytics, advertising, permissions, third-party services, and data retention or deletion procedures that apply.

Project-specific policies will be linked here when ready. No claim is being made on this page that these applications collect no data.
